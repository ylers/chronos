# chronos 使用说明

chronos 是一个**原生桌面应用**(PySide6 / Qt6,**不使用浏览器**),用来做三件事:

- **日常事物记录**:一句话记下想做的事,按状态推进。
- **工作流优化**:把长期 / 短期目标组织成「表单」,逐项排序、完成。
- **实验追踪**:为每个实验记录参数、结论和每一次运行。

所有数据都保存在**本地 SQLite 文件**里,离线可用,不依赖任何服务。

---

## 1. 安装与首次启动

本机已配置好环境(详见[开发文档](DEVELOPMENT.md)),正常使用只需三步:

```bash
cd /home/paschen/aaa_daily/proj/chronos

# 1. 首次: 创建 .venv 并安装 PySide6(清华镜像)
uv sync

# 2. 日常启动(使用库)
uv run python run.py
```

> 如果提示 `uv: command not found`,先执行 `export PATH="$HOME/.local/bin:$PATH"`。

启动后左侧是竖排图标栏,共 **6 个面板**:🗒 计划表 · ⚡ 及时行动 · 🧪 实验管理 · 📖 参考 · 🗂 全部条目 · ⚙ 设置。

---

## 2. 界面语言切换

- 打开 **⚙ 设置** → **Language** → 选择 **English** / **中文**,立即生效。
- 语言偏好保存在当前数据库的 `settings` 表中,下次启动沿用。

## 3. 六个面板

### 🗒 计划表(Planner)

面向**长期 / 短期**目标。把目标组织成多个「表单」,例如「读书计划」「本周安排」。

- **左侧**:表单列表。`New Form` 新建(名称 + 可选描述),选中某个表单后右侧显示其条目。
- **右侧**:表单内的条目表格。可
  - `+ Add Item` 添加条目(类别限制为长期 / 短期);
  - 双击条目或 `Edit` 编辑;
  - `Toggle Done` 在「已完成 ↔ 未开始」之间切换;
  - `Move Up / Move Down` 调整表单内的顺序;
  - `Delete Item` 删除条目;`Delete` 删除整个表单(**条目本身保留**,只是脱离表单)。

**右键菜单**:在条目行上点击鼠标右键,可以设置父项、移出父项、`复制`、`转移到表单`、`上移`、`下移`、`删除条目`。转移子菜单只列出其他 planner 表单；成功后 Item 从当前表单移到目标表单末尾。复制会保留名称以外的全部信息、父项和表单归属,名称增加“（副本）”,并插入到原条目后一位。第一行不能上移,最后一行不能下移。

### ⚡ 及时行动(Quick Action)

面向**即时 / 灵感 / 未分类**任务。**顶部输入框回车即加**,这是最常用的入口。

**快加语法**:

```
任务名 !优先级 #类别 *重要度
```

| 记号 | 含义 | 范围 | 默认 |
|---|---|---|---|
| `!N` | 优先级 priority | 0–7(越大越紧急) | 3 |
| `#N` | 类别 category | 0未分类 1长期 2短期 3即时 4灵感 5实验 | 3(即时) |
| `*N` | 重要度 importance | 0–7(越大越重要) | 3 |

例子:

- `打印文件 !7 #3` → 名称「打印文件」,优先级 7,即时任务。
- `读这篇文章 !6 *4` → 优先级 6、重要度 4 的即时任务。

Planner、Quick Action 和 All Items 的列表中，Priority 与 Importance 列直接显示 **0–7 行内滑条**，不需要打开编辑窗口。拖动滑块或把鼠标放在滑条上滚动滚轮即可立即保存，滑条右侧显示当前数值。新建或编辑条目窗口中也提供较宽的滑条和精确数字框。
- `整理博客灵感 #4` → 灵感。

**表单**:右侧 `Form` 下拉可以选一个 **quick 表单**(`New Form` 即时新建)。选中后:
- 快加的新条目会**自动落入**该表单;
- 列表**只显示该表单**的条目(切换表单即切换列表)。
- `按优先级排序` 会重排整个当前表单：优先级从高到低；相同优先级再按重要度从高到低；两者都相同时保持原相对顺序。未选择具体表单时按钮禁用。
- 表单下拉中的“未归档”只显示尚未加入任何 Quick 表单的条目。列表“表单”列显示每条 Item 的实际归属；右键 Item →“转移到表单”可把未归档条目加入表单、在 Quick 表单之间转移，或选择“移出表单”重新变为未归档。

> 注意:只有**即时 / 灵感 / 未分类**属于本面板。快加写 `#1` / `#2`(长期 / 短期)或 `#5`(实验)时,条目会按归属创建到对应面板,这里不显示,并会弹出提示——去 **🗂 全部条目** 可以查看。

**列表操作**:

- 每行左侧 ☑ 勾选 = 标记完成;点下方 `Toggle Done / Restore` 可以恢复。
- `Scope` 下拉:进行中 / 已完成 / 全部。
- `Category` 下拉:按类别过滤(仅本面板的 4 类)。
- 搜索框按名称 / 描述关键字过滤。
- 双击条目或 `Edit` 编辑、`Delete` 删除。
- 在条目行上点击鼠标右键可以设置/移除父项、`复制`、`转移到表单`、`上移`、`下移` 或 `删除条目`;副本保留当前 quick 表单归属。上移/下移只有选中了具体 quick 表单时可用；“未归档”视图没有唯一手动顺序，因此移动项会禁用。

### 🧪 实验管理(Experiments)

面向**实验**类条目,左右分栏:

- **左**:实验列表(名称、状态、结论摘要、更新时间)。
- **右**:选中实验后编辑详情:
  - **名称 / 描述**;
  - **Parameters 参数表**:键值对。值会自动尝试解析为 JSON 数字 / 布尔 / 对象(例如填 `1e-3` 会变成字符串,填 `50` 会变成数字);`+ Key/Value` 加行、`− Key/Value` 删行。
  - **Result 结论**;
  - **Runs 运行记录**:`+ Add Run` 为每次运行留痕(记录时间 + 备注),形成迭代历史。
- 改动记得点 `Save Changes`。
- 列表 `New Experiment` 新建、`Delete Experiment` 删除(连同其参数 / 结论 / 运行记录)。
- 在实验行上点击鼠标右键可以 `复制` 或 `删除条目`;复制会同时保留实验参数、结论和运行记录。

### 📖 参考(Reference)

一张「说明书」,展示:

- **fix feature 字段**:类别 / 优先级 / 重要度 / 状态的位宽、取值、含义,以及编码方式。
- **当前设置**:界面语言、背景色、强调色、深色主题、字号——**随设置面板改动实时刷新**。
- **条目与快加**:条目结构、快加语法、类目归属规则。

### 🗂 全部条目(All Items)

一处**浏览和管理所有条目**(跨全部 6 个类别)。适合全局查找、清理。

- 过滤行:关键字搜索、`State` 状态过滤、`Category` 类别过滤、`Sort` 四种排序(更新时间 / 创建时间 / 优先级 / 重要度)。
- 双击或 `Edit` 编辑、`Toggle Done` 完成切换、`Delete Item` 删除。
- 在条目行上点击鼠标右键可以 `复制` 或 `删除条目`。副本会保留原条目的兼容表单归属。

### 完成时间

- Item 每次从非完成状态切换为“已完成”时，系统记录完成时间。
- 取消完成不会清空或改写上一次完成时间。
- 取消后再次完成，会把完成时间更新为这一次的时间。
- 仅编辑名称、描述、优先级等字段不会改变完成时间。
- All Items 的“完成时间”列可统一查看；命令行 JSON 输出包含 `completed_at`。

### 父项与子项

- 一个 Item 可以拥有任意多个直接子 Item；一个子 Item 最多只能有一个直接父 Item。
- 支持多层嵌套。子项在 Name 列紧跟父项显示，并以 `↳` 和逐级缩进表示深度。
- 有子项的父 Item 名称前显示独立的圆角箭头按钮；直接点击按钮即可折叠或展开整个后代树。子项通过留白逐级缩进，不再向名称中添加符号。右键“折叠子项 / 展开子项”仍作为备用入口。折叠只影响显示，不修改或删除 Item；折叠状态会在重启后恢复。
- 右键 Item →“新建子项”可直接创建并缩进到该父项之下；新子项默认继承父项的类别、优先级和重要度，并恢复为“未开始”状态。在 Planner / Quick 表单中，新子项还会继承父项的表单归属。
- 右键 Item →“设为子项（选择父项）”可把已有 Item 变成子项；右键子 Item →“移出父项”解除关系。
- 系统拒绝把 Item 设为自己的父项，也拒绝形成循环结构。
- 删除父 Item 不会删除子 Item；其直接子项会自动成为根 Item。
- 父子关系与 Form 归属相互独立。筛选结果中若父项不可见，子项仍会作为当前结果的根行显示。
- 已完成的条目在表格中显示删除线。

### ⚙ 设置(Settings)

| 设置项 | 说明 |
|---|---|
| Language | 界面语言:中文 / English,即时生效 |
| Background color | 主背景色,点击色块打开取色器 |
| Accent color | 选中与高亮的强调色 |
| Dark theme | 深色主题开关 |
| Font size | 基础字号(10–22px) |

所有改动**立即生效**并写入数据库。面板底部会显示**当前数据文件路径**,便于确认你在用哪个库。

### 界面尺寸自动保存

应用会把以下布局尺寸保存到**当前数据库**的 `settings.ui_layout`，下次启动自动恢复：

- 关闭前所在的左侧页面；
- Planner 当前选中的表单；
- Quick Action 当前选中的表单（包括“未归档”）；
- 主窗口大小、位置和最大化状态；
- Planner 左侧 Form 列表与右侧 Item 表格的分栏宽度；
- Experiments 左侧实验列表与右侧详情的分栏宽度；
- Planner、Quick Action、Experiments、Reference、All Items 的主要表格列宽；
- Experiments 参数表列宽。

拖动时使用约 250ms 防抖保存，关闭窗口时立即保存。使用库和开发库分别保存布局，因此互不影响。

Item 表格名称支持自动换行，行高根据内容自适应；短名称保持紧凑，长名称会自动增加行高以显示完整内容。

如需恢复默认布局，退出应用后运行下面的 Python 命令删除当前数据库 `settings` 表中的 `ui_layout` 键；不要删除整个数据库：

```bash
uv run python -c "from chronos_app.model import Database; db=Database('data/chronos.db'); db.set_setting('ui_layout', {}); db.close()"
```

开发库需要把路径改为 `data/chronos-dev.db`。

## 4. 开发库与使用库分离

chronos 默认把**日常数据**和**开发 / 演示数据**分开,互不干扰:

| 命令 | 使用的库 | 说明 |
|---|---|---|
| `uv run python run.py` | `data/chronos.db` | **使用库**,日常真实数据 |
| `uv run python run.py --dev` | `data/chronos-dev.db` | **开发库**,可随意折腾 |
| `uv run python run.py --demo` | `data/chronos-dev.db` | 重置开发库并写入演示数据后启动(幂等) |
| `uv run python run.py --db PATH` | 指定文件 | 显式指定库,绕过默认分离 |
| `uv run python run.py --smoke` | 临时库 | 自动截图 + 校验后退出(开发者用) |

- **`--demo` 永不写入使用库**;演示数据只进开发库。
- 打开开发库时,**窗口标题会带 `[dev]`**,一眼可辨当前在哪个库。
- 设置面板底部也会显示当前库的完整路径。

## 5. 条目模型速览

每个条目 = **定长特征(fix feature)** + **变长参数(extendable)**:

```
item = 名称 + 描述 + fix feature + extendable(JSON)
```

fix feature 用一个 16 位整数紧凑编码:

```
state(2 位) | importance(3 位) | priority(3 位) | category(8 位)
```

| 字段 | 取值 | 含义 |
|---|---|---|
| category 类别 | 0 未分类 / 1 长期 / 2 短期 / 3 即时 / 4 灵感 / 5 实验 | 条目归属 |
| priority 优先级 | 0–7 | 越大越紧急 |
| importance 重要度 | 0–7 | 越大越重要 |
| state 状态 | 0 未开始 / 1 准备做 / 2 遇障碍 / 3 已完成 | 当前进度 |

**面板归属(互斥)**:

| 类目 | 所属面板 | 可入表单 |
|---|---|---|
| 长期 / 短期 | 🗒 计划表 | 计划表表单 |
| 即时 / 灵感 / 未分类 | ⚡ 及时行动 | quick 表单 |
| 实验 | 🧪 实验管理 | 不入表单 |

任一条目**只属于一个面板**,不会同时出现在计划表和及时行动中;两个面板的**表单互不共享**。如果在一个面板里把条目改成别的类目,它会自动从原表单中移出。

## 6. 数据文件与备份

所有数据位于 `data/` 目录:

```
data/
  chronos.db        使用库(真实数据)
  chronos-dev.db    开发库(演示 / 测试数据)
  *.backup.db       历史备份
```

**建议**:定期备份使用库,把 `data/chronos.db` 复制一份(例如拷到网盘)即可,SQLite 单文件,拷贝即备份。恢复同理,把备份文件放回覆盖即可。

## 7. 常见问题

**Q: 快速添加后任务没出现在及时行动里?**
看一下提示弹窗——你用了 `#1`/`#2`/`#5`(长期 / 短期 / 实验),它被创建到了对应面板。到 🗂 全部条目 查看,或改成 `#3`(即时)。

**Q: 想给一个任务换个表单?**
及时行动面板选到目标 quick 表单,编辑该条目的类别不动(仍是即时等 quick 类目)即可;或先删除再从目标表单添加。计划表同理:先在原表单 `Delete Item`(只移出表单不删条目),再到目标表单 `+ Add Item`。

**Q: 切了语言有些按钮没变?**
语言即时生效;个别对话框里已打开的中文不会变,关闭重开即可。

**Q: 如何彻底重置?**
日常使用别碰 `data/chronos.db`。想重置开发库:删掉 `data/chronos-dev.db`,再 `uv run python run.py --demo` 重建。
